# java-lotto-precourse

## 기능 구현 목록

### 1. 입력 기능 (InputView)

- 로또 구입 금액을 입력 받는다.
- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
- 보너스 번호를 입력 받는다.

### 2. 출력 기능 (OutputView)

- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
- 당첨 내역을 출력한다.
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

### 3. 로또 클래스 (Lotto)

- 제공된 Lotto 클래스를 사용하여 구현
- 특정 번호 포함 여부를 확인한다.
- 로또 번호 목록을 반환

### 4. 당첨 로또 클래스 (WinningLotto)

- 당첨 번호(Lotto)와 보너스 번호를 저장한다.
- 보너스 번호 검증 (1~45 범위, 당첨 번호와 중복 없음)
- 구매한 로또의 등수를 판정한다.

### 5. 등수 Enum (Rank)

- 등수별 일치 개수, 보너스 일치 여부, 상금을 정의한다.
- 일치 개수와 보너스 일치 여부로 등수를 판정한다.
- 등수의 상금을 반환한다.

### 6. 당첨 결과 클래스 (LottoResult)

- 구매한 로또들과 당첨 번호를 비교하여 등수별 당첨 개수를 계산한다.
- 총 당첨 금액을 계산한다.
- 수익률을 계산한다.

### 7. 로또 구입 클래스 (LottoStore)

- 구입 금액을 받아 검증한다. (양수, 1,000원 단위)
- 구입 금액으로 로또 구매 개수를 계산한다.
- LottoMachine을 사용하여 로또를 발행한다.

### 8. 로또 생성 클래스 (LottoGenerator)

- 1~45 범위에서 중복 없이 6개의 숫자를 랜덤으로 생성한다.
- 생성된 숫자로 Lotto 객체를 생성한다.
- 지정된 개수만큼 로또를 생성한다.

### 9. 게임 컨트롤러 (LottoController)

- 구입 금액 입력 및 검증 (양수, 1,000원 단위)
- 로또 구매 개수 계산 및 발행
- 당첨 번호 및 보너스 번호 입력
- 당첨 결과 계산 및 출력

### 10. 예외 처리

- 모든 검증 실패 시 IllegalArgumentException 발생
- 에러 메시지는 "[ERROR]"로 시작

## TDD 기반 설계

### 1. 도메인

#### 1-1. Lotto 클래스

- 로또 번호가 6개가 아니면 예외 발생
- 로또 번호에 1~45 범위를 벗어난 숫자가 있으면 예외 발생
- 로또 번호에 중복된 숫자가 있으면 예외 발생
- 특정 번호를 포함하는지 확인 (true/false 반환)
- 로또 번호 목록을 반환

#### 1-2. Rank 열거형

- 각 등수의 상금을 정확히 반환

### 2. 비즈니스 로직

#### 2-1. LottoGenerator 클래스

- 지정된 개수만큼 로또 생성

#### 2-2. WinningLotto 클래스

- 당첨 번호와 보너스 번호로 생성
- 보너스 번호가 1~45 범위를 벗어나면 예외 발생
- 보너스 번호가 당첨 번호와 중복되면 예외 발생
- 당첨로또와 비교하여 정확한 등수 반환

#### 2-3. LottoStore 클래스

- 구입 금액이 0 이하면 예외 발생
- 구입 금액이 1,000원 단위가 아니면 예외 발생
- 구입 금액을 1,000으로 나눈 개수만큼 로또 생성

#### 2-4. LottoResult 클래스

- 등수별 당첨 개수를 정확히 계산
- 수익률을 정확히 계산 (소수점 둘째자리 반올림)

### 3. 통합 테스트

#### 3-1. 전체 게임 흐름 시나리오

- 구입 금액 입력 → 로또 발행 → 당첨 번호 입력 → 결과 출력 정상 동작

### 4. 예외 처리 테스트

#### 4-1. 입력 예외

- 구입 금액에 문자 입력 시 예외 발생
- 당첨 번호에 6개가 아닌 숫자 입력 시 예외 발생
- 당첨 번호에 쉼표가 없거나 형식이 잘못된 경우 예외 발생
- 모든 예외 메시지가 "[ERROR]"로 시작

#### 4-2. 도메인 예외

- LottoStore에서 잘못된 금액으로 예외 발생
- WinningLotto 생성 시 잘못된 번호로 예외 발생
- Lotto 생성 시 잘못된 번호로 예외 발생
